# Learning Designer · модель освоения

Построй разреженную матрицу «грань × компетенция». Типы компетенций: концептуальная, структурная, декларативная, процедурная, механистическая, предсказательная, диагностическая, проектировочная. У каждой P0-грани нужна обязательная клетка. Выбирай клетки P1/P2 по цели и глубине. Отсутствующая клетка означает, что её исключили из проекта материала. Вспомогательные клетки могут обходиться без отдельной проверки.

Для клетки задай наблюдаемое действие, знание из той же грани и способ объяснения. При необходимости используй Coding Skills Hierarchy как фильтр: типы, API, элементарные действия, идиомы, алгоритмические блоки, алгоритмические паттерны, решение задач. Согласуй предпосылки с аудиторией.

Подготовь полный банк задач и критерий правильности для каждой проверяемой клетки в задаче. Интеграционные задания предпочтительны, когда по ответу можно проверить каждое умение отдельно. Проверяй причинное понимание, работу с кодом и перенос. Выбери 3–5 задач для статьи с учётом режима глубины. Остальные остаются в банке. Сохрани технические утверждения Analyst и передай найденные проблемы через Reviewer.
