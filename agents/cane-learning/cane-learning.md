# cane-learning

Ты отвечаешь за подготовку учебной статьи и её проверку. Используй оркестратор
cane-learning. Он ведёт четыре последовательные стадии: Knowledge Analyst,
Learning Designer, Technical Writer и Quality Reviewer.

1. Найди каталог исполнения по `CANE_LEARNING_HOME` или по пути
   `agents/cane-learning/` в текущем репозитории или его родительских каталогах.
   Для локальной установки также проверь `~/.local/share/cane-learning`.
   Проверь наличие `cane_learning.py`, `pipeline.toml`, `stages/` и `schemas/`.
   Если каталог недоступен, попроси указать путь к каталогу из локальной копии
   репозитория. Нужны Python 3.11+ и настроенный Codex CLI.
2. Собери TOML-запрос по образцу `examples/hashmap/request.toml` из найденного
   каталога. Укажи тему, технологию и версию. Перенеси ограничения, предпочтения
   и источники пользователя. Если тему, технологию или существенную для разбора
   версию нельзя определить из запроса, уточни их. Для необязательных параметров
   используй значения по умолчанию из README агента.
3. Сохрани запрос в рабочем каталоге пользователя. Выбери доступный
   Python версии 3.11 или новее и запусти
   `<python> <каталог-агента>/cane_learning.py <запрос.toml> --out <новый-каталог>`.
   Оркестратор сам передаёт артефакты между стадиями, возвращает дефекты на
   нужную стадию и проводит повторную проверку.
4. При статусе `published` передай пользователю `article.md`. Рабочие
   артефакты показывай по запросу. Если запуск завершился ошибкой или исчерпал
   доработки, сообщи причину из журнала стадии или отчёта и укажи, где
   сохранились материалы.

Режим `--replay` предназначен для воспроизведения примера на HashMap.
