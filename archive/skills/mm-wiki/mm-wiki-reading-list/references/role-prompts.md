# Категории книг → промпты (справка, не источник правды)

Источник правды — теги в самой вики: страница `Wiki/Prompts/*` с тройкой тегов
`#KB #Books #mm-wiki` в её `tags::` — это доступная категория. Этот файл только
объясняет критерий отнесения книги к странице; тела промптов здесь не
дублируются — промпт читается из вики при каждой генерации (см. SKILL.md,
Step 2).

Обнаружение в рантайме: grep по `pages/Wiki___Prompts___*.md` на строку
`tags::`, содержащую одновременно `#KB`, `#Books`, `#mm-wiki`.

## Действующие категории (на 2026-09-23)

| Категория | Критерий отнесения книги | Страница промпта |
|---|---|---|
| Профессиональные / технические книги | software engineering, system design, architecture, product/project management, data engineering, DevOps, security, бизнес-анализ — книги, которые дают методы/фреймворки для профессиональной практики | `[[Wiki/Prompts/Professional-Book-Brief]]` |
| Научпоп / психология / саморазвитие | бизнес, психология, саморазвитие, поведение человека, продуктивность, принятие решений, лидерство, экономика поведения, социальная психология, neuroscience в прикладном контексте, личные финансы, предпринимательство, коммуникация, привычки | `[[Wiki/Prompts/Nonfiction-Book-Brief]]` |

`Wiki/Prompts/Book-Summarization` (конспект по главам с цитатами) намеренно
**не** в этом списке — пользователь решил её не использовать для этого скила
(2026-09-23); теги `#KB #Books #mm-wiki` с неё сняты. Если понадобится вернуть
— вернуть тег на странице, скил подхватит автоматически без правки кода.

## Когда ни одна категория не подходит уверенно

Не выдумывать третий вариант и не силой запихивать книгу в одну из двух
существующих категорий. Поведение по режиму — см. SKILL.md
(«Классификация категории»): `list`/`single` помечают книгу как «нужен новый
промпт», `full` пропускает её и выносит в отдельный список отчёта.

Когда для новой категории пишется новая страница `Wiki/Prompts/<X>-Book-Brief`
— обязательно тройка тегов `#KB #Books #mm-wiki`, и эту таблицу стоит обновить
строкой (не обязательно, механизм работает и без обновления файла — но так
критерий остаётся читаемым для человека).
