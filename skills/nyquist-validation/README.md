# Nyquist Validation

Аудит достаточности проверок: какие нарушения требований и инвариантов обнаружат
существующие тесты и где нужны дополнительные наблюдения или сценарии.

Связывает требования с поведением, наблюдаемым результатом, assertion и командой
запуска. Работает с OpenSpec и обычными репозиториями. В режиме `fill` добавляет
тесты; дефекты реализации выносит в отчёт. Не требует Obsidian во время запуска.

Примеры:

- «Проверь покрытие требований checkout существующими тестами, ничего не меняй».
- «Закрой тестами пробелы OpenSpec change `payment-retries`».
- «Проверь все сценарии изменения `owner-only-delete`, учти delta specs».
- «Спланируй проверки идемпотентности перед реализацией платежей».

Режимы: `audit` — чтение и отчёт; `fill` — тесты и отчёт; `plan` — будущие проверки
без заявления о пройденной валидации. Язык ответа соответствует запросу.

Сборка из корня репозитория:

```bash
bash scripts/package-skill.sh nyquist-validation
```

Поддержка OpenSpec: [requirements и delta specs](references/openspec.md).
GSD оставлен только в [происхождении метода](references/sources.md).
Это инженерный подход к достаточности
проверок, не математическая гарантия корректности.
