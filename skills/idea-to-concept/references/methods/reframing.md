# Reframing — Changing the Frame

> The same fact can be an obstacle or an opportunity depending on the
> frame around it. Reframing deliberately changes that frame — the
> context in which the problem is viewed — to reveal a non-obvious
> solution or a different hypothesis.

## Origin

From cognitive psychology (e.g., Gregory Bateson's and Paul
Watzlawick's work on reframing in communication). A fact is not
interpreted in a vacuum — it is interpreted within a frame; change the
frame and the meaning changes.

## Application to Problem Analysis

When a problem looks like a pure liability, reframing tests whether the
liability is actually a hidden asset.

### 1. Name the Current Frame

State the problem in its default framing, including the implicit
judgment.

> "High price is a problem that scares customers away." (frame:
> obstacle)

### 2. Invert the Frame

Interpret the same fact as an advantage, a filter, a signal, or an
asset.

> "High price is a filter that attracts only the solvent customers
> willing to pay for premium service." (frame: advantage)

### 3. Derive the New Hypothesis

Extract the new question the reframed fact suggests.

> "How do we emphasize the premium quality enough to justify the
> price?"

### 4. Sanity-Check the Reframe

The reframe must remain true to the facts — it is a change of
interpretation, not a change of data. If the new frame contradicts the
evidence, it is wishful thinking, not reframing.

## When to Use

A problem framed only as a liability ("this is a problem", "this is
unavoidable", "customers hate this"), or a situation where the obvious
frame has been accepted without question.

## Output

The original frame, the reframed interpretation, the new hypothesis it
produces, and a check that the reframe stays true to the facts.
