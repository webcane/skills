# Changelog

Все значимые изменения этого скилла.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] - 2026-07-30

### Added
- Первая версия скилла `python-algo-coach` — интерактивный тренер по
  алгоритмическим задачам на Python уровня LeetCode Easy/Medium.
- Тестовый харнесс `scripts/run_tests.py`: прогон решения по тестам, скаффолды,
  подсказки по уровням, фильтры по паттерну и сложности, самопроверка банка.
  Ловит неверный ответ, исключение, бесконечный цикл (таймаут через
  `signal.setitimer`), нарушение in-place и цикл в возвращённом связном списке.
  Узлы списков и деревьев принимаются по duck typing — решение может определять
  свои классы `ListNode`/`TreeNode`.
- В `--show` условие, подпись и примеры идут первыми, а `Паттерны:` и `Цель:` —
  в подвале под заголовком «спойлеры», каждое с пометкой, до какого шага его
  нельзя произносить. В свёрнутом выводе терминала видна верхняя часть, поэтому
  примеры не должны быть внизу.
- Целевая сложность раскрывается только на Шаге 4 — после того, как пользователь
  назвал свою оценку. Убрана из трёх мест, где утекала автоматически: docstring
  заготовки `--scaffold`, вопрос-прогноз на Шаге 2 и сообщение «ВСЁ ЗЕЛЁНОЕ»
  после успешного прогона. Для явного показа добавлена команда `--target <id>`
  (цель + паттерн + типичная ошибка). Шаг 4 разводит три исхода — попадание,
  код в цель при неверной оценке, код хуже цели.
- Заготовка `--scaffold` заканчивается подписью с `:` и телом `pass` — валидный
  Python, готовый к заполнению. Поскольку `pass` возвращает `None` молча (и на
  задачах вроде `move_zeroes` часть тестов тогда «проходит»), добавлена проверка
  на незаполненную заглушку: тесты не запускаются, печатается «решение не
  написано», exit code 1.
- Банк из 40 задач (`references/PROBLEMS.json`), 191 тест-кейс, 14 паттернов.
  У каждой задачи: целевая сложность, поле `trap` с типичной ошибкой и 3 уровня
  подсказок. Пять режимов сравнения ответа: `exact`, `unordered`, `groups`,
  `inplace`, `inplace_k`.
- 40 эталонных решений (`references/solutions/`), все проходят свои тесты.
- `references/PATTERNS.md` — 12 паттернов «джентльменского набора» плюс связные
  списки: суть, признак применимости, ограничения, питоновские шаблоны, ловушки,
  таблица «признак → паттерн».
- `references/REVIEW-CHECKLIST.md` — пятиуровневый разбор решения: сложность,
  соответствие паттерну, границы, питоновость, формулировка для интервью.
  Таблица скрытых O(n)-операций Python.
- `references/CONFIG.md` — пути, требования, формат лога тренировок,
  схема записи задачи и инструкция по добавлению новых задач.
- Четыре режима работы: тренировка, разбор паттерна, диагностика слабых мест,
  проверка готового решения.
