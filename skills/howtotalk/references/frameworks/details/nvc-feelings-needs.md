## Faux Feelings / Pseudo-Feelings

These words LOOK like feelings but actually contain an evaluation of what someone ELSE is doing. Avoid using these in NVC:

| Faux Feeling | Hidden Judgment | Try Instead |
|---|---|---|
| abandoned | "You left me" | lonely, scared, hurt |
| abused | "You're abusing me" | angry, frightened, hurt |
| attacked | "You're attacking me" | scared, angry, tense |
| betrayed | "You betrayed me" | shocked, hurt, angry |
| blamed | "You're blaming me" | angry, scared, confused |
| bullied | "You're bullying me" | scared, angry, powerless |
| cheated | "You cheated me" | angry, hurt, disappointed |
| coerced | "You're forcing me" | resentful, scared, angry |
| dismissed | "You're dismissing me" | hurt, frustrated, lonely |
| ignored | "You're ignoring me" | lonely, hurt, sad |
| insulted | "You insulted me" | angry, embarrassed, hurt |
| intimidated | "You're intimidating me" | scared, anxious |
| judged | "You're judging me" | tense, nervous, self-conscious |
| manipulated | "You're manipulating me" | angry, scared, powerless |
| misunderstood | "You don't understand me" | frustrated, discouraged |
| neglected | "You're neglecting me" | lonely, sad, hurt |
| pressured | "You're pressuring me" | anxious, overwhelmed, resentful |
| provoked | "You provoked me" | angry, frustrated |
| rejected | "You rejected me" | hurt, scared, lonely |
| taken for granted | "You take me for granted" | sad, hurt, frustrated |
| unappreciated | "You don't appreciate me" | sad, discouraged, hurt |
| unsupported | "You don't support me" | lonely, discouraged |
| used | "You're using me" | angry, sad, hurt |

## Quick Reference: The 4-Step Template

```
When I [see/hear/notice] ___ (observation),
I feel ___ (feeling),
because I need ___ (need).
Would you be willing to ___? (request)
```

## Key Distinctions

| Concept | This IS it | This is NOT it |
|---------|-----------|----------------|
| Observation | "You spoke for 20 minutes" | "You dominated the meeting" |
| Feeling | "I feel anxious" | "I feel you don't care" |
| Need | "I need predictability" | "I need you to be on time" |
| Request | "Would you text me by 5pm?" | "Stop being inconsiderate" |
