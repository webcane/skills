Проведи инженерную диалектику по skill `engineering-dialectic`.

Разбери их так:

- первый токен — режим, если это `independent`, `positions` или `hybrid`;
  по умолчанию `independent`;
- остальное — цель, обязательные требования и ссылки на первичные материалы.

Дальше:

1. Загрузи `engineering-dialectic/SKILL.md`, прочитай `references/protocol.md`

2. Зафиксируй предварительную позицию до вызова решателя. Не показывай её
   решателю и не передавай ему список вариантов.
3. Выполни выбранный режим, выставь `procedure`, `decision` и `blindness`.
4. Верни отчёт по шаблону `assets/decision-template.md` из каталога skill
   в чат. Ничего не записывай в файлы и не меняй код: если пользователь
   просит сохранить результат, сообщи, что запись выполняет родительский агент.
