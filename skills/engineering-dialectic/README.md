# engineering-dialectic

Инженерное решение с проверенными основаниями: независимый решатель,
дискриминатор утверждений и выборочное экспертное опровержение. Результат —
решение, его границы и исполнимый план проверки, а не победитель спора.

## Режимы

| Режим | Когда |
| --- | --- |
| `independent` (по умолчанию) | Неясна полнота вариантов или недостаточно оснований для выбора |
| `positions` | Нужно сравнить известные варианты или заданные приоритеты |
| `hybrid` | Независимый проход, затем подробное сравнение найденных вариантов |

## Установка

Skill ставится как обычно (из корня хаба):

```bash
bash scripts/install-local.sh engineering-dialectic --target opencode
```

Сила метода — в изоляции участников, поэтому одного skill мало: нужен агент
с субагентами и ограниченными правами. Профили OpenCode V2 собираются из
`agents/engineering-dialectic/` и устанавливаются в проект:

```bash
python3 agents/engineering-dialectic/build_opencode.py --output /path/to/project/.opencode/agents
```

Подробности, ограничения и проверка — в
[README агента](../../agents/engineering-dialectic/README.md).

Входная команда `/dialectic` (необязательна, требует установленного агента):

```bash
scripts/install_commands.py --host opencode --dest /path/to/project
```

## Состав

- `SKILL.md` — маршрутизация по режимам и границы выполнения.
- `references/protocol.md` — этапы, бюджеты, условия остановки.
- `references/evidence-contract.md` — виды утверждений, формат находок, доступ к данным.
- `references/role-prompts.md` — канонические промпты ролей; из них собираются адаптеры.
- `references/method-comparison.md` — отличия от дебатов и голосования.
- `references/use-cases.md` — примеры запросов.
- `assets/decision-template.md` — шаблон итогового решения.
- `assets/commands/` — входная команда для хостов.

## Происхождение

Взято из [kites262/engineering-dialectic](https://github.com/kites262/engineering-dialectic):
идея состязательной проверки инженерного варианта, роль ведущего как судьи и
требование не выдавать согласие за подтверждение.

Переделано: вместо фиксированных раундов дебатов между заданными позициями —
слепой независимый решатель, дискриминатор проверяет утверждения по первичным
источникам, а эксперты ищут конкретный сценарий отказа. Добавлены контракт
свидетельств, маркировка слепоты и разделение `procedure` и `decision`.
Исходный протокол не переносился: текст upstream не переиспользуется.
